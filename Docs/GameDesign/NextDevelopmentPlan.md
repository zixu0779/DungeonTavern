# 后续开发与修正计划

审计日期：2026-10-01。依据当前脚本、主场景序列化配置、人物动作资产、已有验证记录及本轮对话中的用户验收。
本次审计以文档与实现核对为主；清理与节奏调整后已运行多人点单专项测试，通过四人排队/点单、共享拒绝与通过、代餐、用餐和结账检查。其余入口未全部重跑，专项通过不等于完整 Demo 验收。

## 状态与范围

- **已完成**：实现已有且对应范围已验证或用户认可，不再列为待开发。
- **待验收**：实现已有，需要重新走一遍指定流程，确认后续修改没有影响它；这就是“回归检查”，不表示该功能尚未实现。发现问题后再立修复项。
- **待开发**：已提出但尚未实现的内容。
- **待讨论**：没有确定玩法或技术方案，不自动进入制作。
