# 后续开发与修正计划

此列表记录待办，不代表已实现或已确定技术方案。

1. **人物风格设计**：以当前满意的 KayKit 占位人物为风格参考，确定主角和重要人物的比例、轮廓、配色与服装；结合剧情保留角色身份特征。
2. **人物穿墙问题**：检查角色身体、动作位移、墙壁碰撞和导航边界，区分真实穿模与视角遮挡，逐项修正。
3. **顾客交互验收**：当前已按可见身体位置、距离和朝向选择上餐／结账对象，并拒绝隔墙交互；后续根据人工试玩调整手感。
4. **顾客朝向验收**：当前圆桌朝向中心，长桌侧边和端部座位分别垂直朝向对应桌边；先转身再落座，等待与起身保留朝向。继续检查实际服务流程中的视觉效果。
5. **大门外的小范围场景**：设计门外过渡区域、顾客出现和消失位置、地面与墙壁衔接。酒馆仍位于地下城内部，不将这里设计成地下城入口。
6. **NPC AI 引入探讨**：先盘点现有状态机和寻路的不足，再讨论适合 Demo 的行为方案、工作量与表现收益；尚未确定引入新框架或复杂自主行为。
