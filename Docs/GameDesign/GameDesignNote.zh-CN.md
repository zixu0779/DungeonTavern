# 地下酒馆——游戏设计约定

[English](GameDesignNote.md) | **简体中文**

本文是已确认玩法与世界设定的长期依据。**待讨论事项**明确未定，未经确认不能实现为最终系统。

## 已确认的世界与玩法约定

- 游戏是以地下城酒馆经营为核心的像素美术 RPG。
- 酒馆位于地下城某层的偏僻角落，不在地下城入口。
- 开头可以表现角色进入地下城，但该段属于独立序章场景。
- 玩家是酒馆老板，通过处理酒馆事务了解世界并推进故事。
- 2.5D 叙事有三种形式：少量开场/回忆镜头可用旁白；简短现场反应使用头顶气泡；包含分支的老板/NPC 交谈使用近景镜头及屏幕下方对话/选项。
- 可选观察和追问返回对话中心；每个中心都有独立动机的推进选项。有意义的选择要么有意汇合，要么留下后续结果。
- NPC 主动交谈区分 4.2 米触发范围与 2.7 米说话距离（当前间距由 1.35 加倍）。墙体阻挡触发，标记的吧台不阻挡。触发后锁住玩家位置、转向 NPC 并启动近景过渡；NPC 沿可行走路径接近，必要时绕员工门，直到距离足够且双方连线通畅才正式说话。接近停滞时释放玩家，不在远处硬开对话。
- 近景镜头在人物连线两侧的垂直方向二选一；每个候选姿态比较 18 条可见性射线（每人 9 条），优先遮挡少者，同分选转角小者。不搜索非垂直角度。人物左右位置可因可见性互换。头顶气泡保持到被新气泡替换或正式对话关闭它。
- 顾客在菜单前排队点单，再前往已预留座位；原地接餐、进食、结账后离开，不另设结账队列。
- 顾客步速与玩家配置步速一致，伊芙快 8%。
- NPC 在酒馆内使用可行走路径，不直接向目标直线移动。主动对话需要双方视线通畅，标记吧台例外；可绕吧台接近，不能隔墙触发。
- 坐姿占据实际凳面，导航接近点和坐姿位置分开，身体不占过道。座位朝向按实际桌面网格中心/轴线决定，不按凳子分布推断。圆桌朝桌心，长桌垂直桌边向内。顾客先转向再坐下，服务及站起时保持朝向，跨层隐藏再显示时保持坐姿动画。交互按 2.4 米内可见身体测距，优先玩家前方近处客人，拒绝穿墙连线。
- 餐具结账后自动消失，当前 Demo 不包含手动回收。
- 老板可在服务期间随时打烊。仍有客人或待到店波次时走临时闭店：感叹气泡喊话，转向大厅但保持可移动和交互；客人一起离开，显示随机符号抱怨，全部离开后关入口。不切入口镜头；未结账订单取消且不加收入，未生成波次保留供再开店，不替代布兰剧情。转身平滑并让位于移动输入。正常闭店要求无人、无后续客流且伊芙已提醒，不触发老板喊话；伊芙只在服务和第一日剧情门控完成且仍营业时提醒。
- UI 使用独立分层 Overlay Canvas，共享暗铁、铜与羊皮纸主题。布局见 `Docs/Art/UIDesign.md`，后续工作见 `Docs/GameDesign/NextDevelopmentPlan.md`。
- 经营 HUD（金币/人数图标和数值）、M 与实体账簿在伊芙首次对话到达开店拉杆阶段后解锁。HUD 分步淡入/滑入只播一次，换层不重播。
- 对话显示当前句和独立选项，使用模型立绘；回顾和暂停菜单可访问完整历史。显示正文仅去掉外引号，历史保留原句。姓名牌适配名称并居中。选项居中、无编号、仅鼠标选择，历史仍保留原文；位置固定、不滚动。多个选项与前一句同时呈现；单选项作为主角动作/语言显示在主对话框并继续，不生成按钮。
- 对话相机朝向垂直于人物连线，在两侧候选中按 18 射线遮挡数及转角选择；正交视线忽略 Trigger 和其他角色。构图过渡 1.3 秒。建筑遮挡用朝相机的局部世界空间切口，不整墙淡隐。
- 切口资格按 Hierarchy 中完整墙面分组，含固定门框与相应建筑构件。实际遮挡启动共享切口；遮挡时预测后续 0.3 秒运动，最远 0.65 m，并由实际碰撞净空裁剪；停止但仍遮挡时保留有效预测。加载时展示已经准备好的切口，不播放启动开孔。新墙组以 0.22 秒进入现有范围，不单独长孔。未命中墙组不变，无遮挡时不启动预测；转角拆墙组，对话合并双方命中组。
- 探索使用主角球形探测，窄门也能触发；对话连接双方完整轮廓为连续开孔，NPC 切口仅用于对话。地板、碰撞和交互阻挡不变。遮罩平滑跟随并使用稳定移动尺寸。截面复用墙面纹理和颜色。B1 石门参与，小型石门保留其原有渲染限制。
- 小型铰链门扇在所有状态保持不透明，固定框共享切口；门状态不暂停周围墙体溶解，楼梯和其他非墙道具保持不透明。切面渲染不改碰撞。F1/B1 地面延伸到墙下支撑截面视觉，楼梯井保持空。
- 主角按角度用 0.35–1 秒转向说话对象，临时闭店转身同速并让位于移动。
- 轻量引导在入层时提示 B1/F1，并记录首次成功起身、出口、拉杆、菜单、取杯、接酒、上菜、结账。开局即在暂停旁提供入口，八项全部完成才消失。当前步骤可执行 25 秒仍未完成时，以 3 秒周期暖金呼吸且暗部保留光。点击同时展开/收起卡片和路线；步骤间显示安静等待说明，无路线。
- 未完成的 F1 引导在 B1 保留，暂时指向返回楼梯，回到 F1 恢复。暂停、对话、账簿、转场不计时；本轮完成不重复，提前完成也记录。不新增任务日志、奖励或成长系统。
- 暂停冻结模拟与输入，有禁用的存取档、操作说明和退出确认。菜单含菜品总览（待上数量/客人数）及尚未实现详细内容的订单标签页。
- 轻量服务流程为菜单排队、确认订单、预留就座、准备送达、进食、结账。一单可有多菜多份，已交部分可先吃，所有份数均交付并吃完才可结账。预留和物理到位分开。
- 第一日使用 FloorLever 开关店，替代吊绳占位。伊芙先走到旁边引导点再说气泡。正常开店/日终闭店临时锁玩家，镜头移到公共入口，开关门并完整播放招牌动画，再返回恢复控制；闭店立即停新客，开店机制结束才开始服务。
- 入口镜头期间 W/A/S/D 或 Q/E 可提前返回玩家；门/招牌继续完成。中断后的回程与去程同长，持续跟随移动中的玩家；提醒前闭店走临时闭店，不切入口镜头。
- 取杯器按当前饮品订单缺杯量，而非新订单事件工作。已交杯覆盖至结账，手持空/满杯覆盖一份未交饮品。仍缺杯时光圈保持，每取一杯补一漂浮杯，缺额归零才停。普通 Demo 用满杯代交任意餐点，因此食物也需杯；正式非替代食物不需杯。共享份数只计一次，先交个人份数再交共享份数。
- 酒桶只填充手持空杯。箱子提示匹配状态，离开自动关闭；盖子动画中保留前一个开/关提示，结束后更新。
- 酒馆平等接待冒险者和地下原住民；只有一个公共入口、一个共享吧台和混合座位，不按种族或阵营划区。
- 老板在一层长期冲突后建立酒馆及和平规则。通往深层的常规路线封闭，唯一受控通路在酒馆下方，所有满足和平条件的种族均可通过，深层居民使用最多。
- 主封印由多层结界、稀有“锚定晶石”、控制核心及过去一次类似 Wish 的现实改写共同构成。老板不能再正常施放 Wish。后来的紧急重配置锁住通路，代价是与封印事件相关的记忆，普通知识及保护力量保留。
- 反派以深层小遗迹出土的唯一遗物绕过封印目的审查。米拉黑石片是同遗迹的另一残留物，不是唯一遗物碎片，也不是第二件等效遗物。可通过魔力、材质或刻痕建立同源联系，第一章不揭露唯一遗物的完整身份/功能。
- 封印室在储藏室下一层；设定上开场镜头后，玩家伏地于此、站起回储藏室，伊芙听到大厅方向动静来会面。

## 酒馆和平规则

- 敌意魔法在酒馆内失效。
- 普通武器仍物理存在并有效，不凭空消失。
- 主动攻击者在伤害发生前被魔法束缚。
- 严重违规者永久拒绝入内。
- 店员和熟客将此视为常识。

具体实现、边界情况和玩法表现仍未定。

## 区域与进度

初始设计范围包括大厅、吧台、混合座位、一个公共入口、厨房和储藏室。

演出区、住宿区、安静包间是可能通过剧情/成就开放的后续区域，条件和顺序未定。酒馆不设常规建筑升级阶梯；开放物理区域不能悄然变成通用升级经济。

## 已确认视觉方向

- 像素美术表现，斜俯视而非完全垂直俯视。
- 墙体必须有可读立面或高度，不能只有地面边界；家具建筑统一斜视角，完全俯视道具不适合最终布景。
- 地下城氛围应暗、封闭、克制，而非明亮户外奇幻；建筑比散置道具更暗，但裂缝、砌体、材质仍需局部可读。
- 既有环境精灵与 3D 模型共存，请求外保留源纹理、切片、网格、材质。旧 Tilemap/Palette 生产流程已退役。

当前美术和目录规范见 `Docs/Art/ArtDirection.md`。

## 待讨论事项

以下不构成设计承诺：轻量服务/每日流程扩展；RPG 属性技能成长和失败状态；事件生成/结算；NPC 日程、AI、关系与声望；详细后续剧情及任务模型；禁斗规则实现；扩展区域开放条件/顺序；当前镜头、碰撞、导航、交互的未来变更；房间边界、家具和流线最终尺寸；最终光照和后处理。

## 当前场景状态与约定

- 箱盖绕后铰链开合。招牌有两个稳定状态及独立开关动画；当前 TavernSign 预制体包含用户调整的机关箱体，改关键帧时保留制作姿态/枢轴。
- 模块吧台、两扇员工门和固定铰链柱组成可复用预制体。门绕竖轴自动开合，不再上掀。`Tavern_Main` 使用 `Assets/DungeonTavern/Art/Models/Bar/Bar.prefab`；旧 Bar_Unified 和专用材质已移除。
- 吧台在 `Tavern_Main/Environment/Bar`，厨房/储藏自动门触发器在 `Environment/Walls/Doors`，可行走地面碰撞在 `Environment/Floor`。Gameplay 是 Tavern_Main 子级，常驻服务名为 Runtime。旧灰盒桌、基础组、旧标记、闲置测试客人、储藏入口和闭店标记已移除。
- F1/B1 储藏楼梯双向连通，第一日剧情启用并引用 `B1Return_StoneStairArrival`；回储藏门控只在宿主内容激活时运行，避免重叠 B1 坐标误触伊芙事件。营业依赖在 F1 可见后的开日时检查。
- B1 场景为 `Assets/Scenes/SealRoom/SealRoom_B1.unity`，独立叠加内容约为酒馆占地三分之一。玩家制作于 B1，运行时常驻后才卸载 B1；Tavern_Main 保持相机、经营、剧情状态；楼梯旅行短淡入淡出。
- 正式构建从 Tavern_Main 进入，初始 B1 内容/玩家就绪前保持黑幕。仅编辑器允许直接播放 SealRoom_B1，临时叠加载入主场景相机和常驻系统；构建不含该便利路径。
- B1 激活时 Tavern_Main 仅保持常驻系统/相机，隐藏环境、人物和玩法内容。运行顾客属于 CustomerPoints 内容根，随楼层隐藏暂停；到店调度暂停，返回时订单和座位预留完整恢复。
- 初次加载保留 B1 制作的玩家位置朝向，不能写死覆盖。传送加载后解析目的场景的到达 Transform，使用当前世界位置朝向；移动它无需改代码，改名/改父级须更新路径。
- Tavern_Main 是酒馆权威工作场景。相机正交、俯角 45°、四向 45/135/225/315°，Q/E 以 0.22 秒旋转 90°，禁鼠标环绕，WASD 移动。
- C 跟随菜单队首点单并走向座位，进入 SeatedIdle 一秒后返回原玩家目标；再按取消，空队列不变，对话或客人失效时恢复。仅改表现不改客人行为；切入/返回为 0.65 秒缓动，途中取消从当前相机位置返回。
- 输出 1920×1080，探索正交尺寸 4.5，对话更近。普通场景 3D 材质 Unlit，柔和光照仅为未来提案。
- 主角为设计 B Humanoid，位移驱动 Idle/Walk，右臂取持层及右手杯锚点；伊芙为独立精灵 Humanoid，顾客仍是 KayKit Barbarian 占位。旧首版主角已清理；Mage/Rogue/Barbarian 原资源留于 ThirdParty，导入不得覆盖。人物等比缩放，肩高超过吧台。
- 顾客服务位置使用 SitDown/SeatedIdle/StandUp；主角也有坐姿及可调用饮用表现，但未加椅子交互或饮酒规则。最终其他 NPC 外观和剧情专属动作仍待制作。
- 仅第一日接通控制器，第二/三日仅 Ink 未完整可玩。当前 Demo 跳过开场文字镜头，玩家伏地，首次移动输入触发面朝下双手撑地站起；后续伊芙剧情启用。站稳前锁移动/F。Space 翻越采用全身动作、手部接触和碰撞控制弧线。
- F1/B1 连通，未完成 F2 入口由碰撞封闭；杯子、酒桶、拉杆和箱子用 F 及状态提示。
- 运行资源直接放 `Assets/DungeonTavern` 下 Art、Gameplay、Narrative、Rendering、Scripts，不恢复 Tavern25D 兼容层。旧 2D 场景、Palettes、Tile 包装已退役，Archive 和场景备份目录不能成为当前依赖。
- 酒馆布局最终内部几何、流线、家具和扩展系统仍需在当前场景评审。集成标记应检查实景，不照抄旧布局；F1 剧情到达目前引用下行储藏楼梯下的 B1Return_StoneStairArrival。

## 第一章人物与后果约束

- 诺克斯为偏中立邪恶的素材买卖商，不是无辜受雇送货者；可亲送高价值/敏感货物。他常向其他买家供应深层素材，但不是酒馆长期深层供应商。老板失踪前主动向他订可疑货，以旧库存说辞下的新鲜货物追查通路；“旧订单”指下单时间，不代表货真是旧的。
- 诺克斯知道可疑，用旧库存掩饰，重利益和可否认性，轻受害者及交易合法性。追问以话术或低成本可见动作暴露闪躲；不必是幕后主使，也不应轻易全盘招供。
- 米拉可自留或委托酒馆保存黑片，选择须持久化并在三日切片之后触发不同内容；各分支收益、风险、结果待定。
- 米拉第二日交谈后立即离店，与后续诺克斯分支无关。诺克斯交易后留饮并产生另一轮服务，除非追问使他明显慌张结巴；仅出汗或移开目光不足以离场，一旦结巴则交易完就走。
- 和平通行不禁止双方普通交换，合法收集/交易的深层素材可流通。可疑货物必须杀害受保护的和平深层生物才取得，新鲜性指向违规猎杀，而非所有深层贸易非法。
- 跨封印货物用“通行申报单”：申报时间、货物、目的及计划存放地，通过后核心盖通行编号。它与酒馆订单/库存记录不同。

## 顾客座位（2026-09-18）

- 孤僻独行优先空长桌、空小圆桌、邻座和对座都空的已占用长桌位置、其他长桌空位、空大圆桌，再到大厅预留站位。
- 热情独行桌型顺序相同，但已占用长桌不按个人空间排序；独行不拼已占用圆桌。
- 结伴 2–4 人随机，独占一张空大圆桌，最后预留组员释放前空凳不开放给其他组或独行。菜单排队中的预留也计占用。
- 普通到店权重孤僻 > 热情 > 结伴，无空大圆桌时排除结伴；Inspector 初值 6:3:1 可调，不是锁定设计比例。
- 组员同时点单但保留个人订单/结账，每人最多两道个人菜和一杯饮品，全组最多两道共享菜。共享显示于所有组员气泡，通过任一成员交付，吃和收费只计一次。
- 上方独立区显示已确认菜，确认图标向上动画；下方显示思考、当前菜、共享提议/投票。成员独立思考，完成当前确认才加入共享讨论。提议者保持菜+问号，其他人先短问号，再独立接受或少量拒绝；一票否决，全票通过才加到全员确认区。全组点完一起去座位。
- 第一日布兰是单人剧情客；普通到店另配。

### 单日 Demo 客流

- 布兰与普通客可同服务期入店。除布兰外恰好六波普通客，每六秒尝试一次，不产生第七波。
- 前三波固定结伴、热情独行、孤僻独行，后面按权重。满座或入口阻挡延期，没有旧五人上限。
- 拉杆可随时走临时闭店；个人账各结，共享菜正常服务时只向首位组员收费一次。

### Demo 菜单与临时代餐

- 共享菜：铁锅洞菇炖肉、炭烤穴猪拼盘。个人菜：盐焗岩薯、黑麦根面包、酸渍洞蕨。
- 酒品：深窖麦芽酒、幽菇淡艾尔、余烬蜂蜜酒。普通客从中选，布兰保留专属饮品订单和剧情结账。

价格和几何菜品图标是原型调参与表现资源，不是最终经济平衡。
